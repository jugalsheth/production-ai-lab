# production-ai-lab — The Compounding Lab

One small proof a week. Each week, one piece of top AI work — reproduced or hardened through a production lens — so that in weeks it reads as a habit, in months as a body of work, and in a year as a corpus.

## The question every module answers

Does this survive contact with reality?

Parity checks. Failure modes. Cost. Latency. If it only works in the demo, it doesn't count.

## How it works

- **One folder per week** — `2026-W47-<slug>/` — runnable code, a README, and a `PRODUCTION-NOTES.md`.
- **Quarterly arcs** — one theme per quarter, so the work compounds instead of scattering.
- **A shared kit** — `lab-kit/` holds the reusable pieces: an eval harness, a cost logger, a parity checker. Each week reuses and extends it.
- **Every week links to the last** — each module's README ends with "Builds on Week N".

## Q1: Proof & evals

Does the AI actually work, and how would you know? Flagship: an open-source Snowflake dependency mapper, built in four weekly slices.

## The rule

Original work, in my own code. Green jobs lie — the lab is where I prove it, one week at a time.
